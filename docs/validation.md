# 北境地窟 MVP 驗收報告

## 固定種子 12345

| 驗收項目 | 規格 | 1,000 次結果 |
| --- | --- | --- |
| 1F 普通戰勝率 | 88–96% | 96.0%（960 勝） |
| 1F 精英戰勝率 | 68–78% | 70.8%（708 勝） |
| 1F 首領戰勝率 | 75–82% | 77.8%（778 勝） |
| 連戰無減員抵達率 | 至少 85% | 85.5%（855 趟） |
| 抵達時剩餘總資源 | 30–45% | 43.08% |

單戰使用標準難度、滿生命與法術位的預設 Lv.1 五人隊伍，開啟自動戰術。每場從相同的角色配置開始，使用種子 12345 衍生獨立戰鬥種子。

連戰使用 Lv.4 的預設五職隊伍。每人投入四點體質與兩點主屬性，戰士穿鎖甲並持鐵邊盾，盜賊持木盾，僧侶持裂銀聖徽，遊俠持紫杉長弓。起始攜帶十二份補給、五支火把、一張卷軸、八份微光藥水與六份強效藥水。面對六場普通戰與一場精英戰，營火以外的紮營可引來伏擊，伏擊計入當段普通戰。藥水可於交戰中治傷，勝利後也可用來喚回瀕死者。抵達率為 94.2%，其中 85.5% 的全部試驗以五人均可行動抵達。

剩餘資源以抵達隊伍為樣本。每一份補給、藥水、卷軸、法術位、完整火把及每位角色的全滿生命條各為一單位，火把餘光與生命按剩餘比例折算。資源分項平均為生命 61.62%、法術位 11.25%、補給 70.15%、照明 67.42%、藥水 32.34%、卷軸 100%。

## 功能確認

- Chromium 模擬 390 × 844 的直式觸控視口。三個主畫面均無水平或垂直溢出。探索視窗高 340 px、小地圖 88 × 88 px、方向鍵 68 × 68 px、探索行動鍵高 85 px。城鎮設施鍵高 84 px，入場主鍵高 76 px。戰鬥指令鍵高 56 px，回合執行鍵高 68 px。
- 以瀏覽器操作驗證開局、招募、探索存檔續玩、手動排令、自動戰術和第一場普通戰。以已訓練隊伍走完兩層首領、區域獎勵、修練場進階、暗室取碗與火塘隱藏王，並驗證重新載入後仍保留進度。
- Node 驗收確認兩層皆為 24 × 24、相同種子的逐回合輸出一致、文字字數與戰報格式符合規格、第二次營火休整無法執行且已擊倒的敵人保持消失。存檔測試驗證 v2 遷移、往返匯出匯入，以及逐位置竄改匯出字串後拒絕匯入。
- 聖潔秘藥依傷勢章節的解除條件可治癒重傷，也會解除輕傷。遊戲使用瀏覽器本地存檔和程式合成音效。
