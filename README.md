# Test RPG3｜北境地窟

直式手機瀏覽器 DRPG。帶領前排三人、後排兩人的小隊，從北境城鎮深入哥布林巢穴與獸人營寨。這版包含六座城鎮設施、兩位守關首領和一位隱藏王。

## 開啟遊戲

在儲存庫根目錄啟動靜態伺服器，再開啟 [http://localhost:8000/](http://localhost:8000/)。

```sh
python3 -m http.server 8000
```

瀏覽器會從 HTTP 載入五份 JSON 資料。可把根目錄直接放到靜態網站主機，無需安裝套件或建置。選取「踏入石階」即可使用預設五人隊伍。難度與存檔匯入、匯出在城鎮右上方的設定中。

## 操作

- **探索**　上、下踏步，左、右原地轉身。電腦可用方向鍵。朝向可疑的牆面，或站上地標後，選取「調查」。
- **補給**　火把熄滅後可在狀態列點火。紮營消耗補給且可能引來敵人，前廳營火每趟可休整一次。
- **戰鬥**　點隊員為各人預排指令，再執行本回合。未下令的隊員會普攻，無法普攻時會防禦。自動戰術依角色抽屜裡的優先序行動。
- **撤離**　入口石階與單向門能通往城鎮。交戰中可在道具與撤離面板安排撤退。回城卷軸在首領戰仍可使用，會遺落半數金幣。
- **存檔**　進度自動儲存在目前瀏覽器與網站來源的 `localStorage`，包含進行中的探索與交戰。文字存檔可在瀏覽器間轉移。

## 驗收

使用 Node.js 18 以上執行固定種子的驗收。指令會列出 1F 三種單戰各千場，以及千趟六場普通戰加一場精英戰的結果。

```sh
node js/simulator.js
```

模擬共用遊戲的規則資料與戰鬥引擎。測試條件、數值與手機版面實測見 [驗收報告](docs/validation.md)。
